@c1|第1章 数制和码制：数值表示
来源：L02 p4-7、L03 p1-4；课本 1.1-1.4，p4-12。
H|本章主线
P|先确定“代码表达什么”和位宽，再解释数值。相同的 1011 可以是无符号数 11、4 位补码 -5，也可以是一组逻辑状态。
H|数制与进制转换
B|基数为 r 的位权表示：整数位从右向左是 1、r、r²……；小数位是 r⁻¹、r⁻²……。
B|其他进制转十进制：逐位乘位权后相加。十进制整数转 r 进制：连续除 r、逆序取余；小数：连续乘 r、顺序取整数部分。
B|二进制与八进制每 3 位一组，与十六进制每 4 位一组；以小数点为分组边界，整数左侧、小数右侧补零。
F|D = Σ aᵢrⁱ；例如 (101.11)₂ = 4 + 1 + 1/2 + 1/4 = 5.75。
H|位宽与数值范围
T|表示方式|N 位取值范围|零与最高位
R|无符号整数|0 至 2ᴺ - 1|最高位也是数值位
R|原码整数|-(2ᴺ⁻¹ - 1) 至 2ᴺ⁻¹ - 1|最高位为符号，有正零、负零
R|补码整数|-2ᴺ⁻¹ 至 2ᴺ⁻¹ - 1|最高位权重为 -2ᴺ⁻¹，零唯一
H|补码运算
B|正数的补码与原码相同；求负数的 N 位补码：将对应正数的整个 N 位字取反，再加 1，保留 N 位。
B|减法转成加法：A - B = A + (-B)。最高位的进位丢弃，结果按原位宽解释。
B|有符号溢出：同号相加却得到异号结果；也可检查符号位的进位输入与进位输出是否不同。无符号进位与有符号溢出需要分别判断。
H|理解例题（根据本章规则整理）
P|4 位补码 0101 + 0011 = 1000。数值 5 + 3 = 8 超出 [-8,7]，1000 被解释成 -8，因此发生溢出。把位宽扩展为 5 位后，00101 + 00011 = 01000，才得到可表示的 8。

@c1|第1章 数制和码制：编码与信息
来源：L02 p4-7、L03 p2-6；课本 1.3-1.5，p6-17；信息量、Huffman 为课件补充。
H|扩展与定点数
B|无符号数扩宽采用零扩展；补码扩宽采用符号扩展，复制原最高位。4 位补码 1011 = -5，扩宽后为 11111011。
B|定点数的小数点位置是约定，不存进代码。若 N 位补码有 F 位小数，数值等于补码整数值除以 2ᶠ，分辨率是 2⁻ᶠ。
F|N 位、F 位小数的补码范围：-2ᴺ⁻¹ / 2ᶠ 至 (2ᴺ⁻¹ - 1) / 2ᶠ。
P|例如 8 位、4 位小数：0111.1000 = 7.5；1000.1000 = -7.5。负数求补码时，加的是最低位的一个单位，此处为 1/16。
H|常用编码
T|编码|用途与特点|复习时检查
R|8421 BCD|每个十进制数字单独使用 4 位|1010-1111 不是有效十进制数字
R|余 3 码、2421、5211|采用不同编码规则表示十进制数字|以具体编码表为准，不能直接当纯二进制
R|格雷码|相邻代码仅一位改变|适用于减小多位同时变化引起的误判
R|ASCII|课件介绍 7 位字符编码|表示字符，不是在表示字符的数值
P|十进制 25 的纯二进制是 11001；8421 BCD 是 0010 0101。后者把“2”和“5”分别编码。码制与数制的区别是本章常见混淆点。
H|信息量与变长编码（课件补充）
F|事件信息量 Iᵢ = log₂(1/pᵢ)；平均信息量 H = Σ pᵢlog₂(1/pᵢ)。
B|等概率的 N 种选择需要至少 ceil(log₂N) 位的定长代码。概率越低的事件，出现时提供的信息越多。
B|Huffman 思路：给高概率事件较短代码，低概率事件较长代码，使用前缀树保证能够逐个解码。
P|课件例：概率 1/3、1/2、1/12、1/12，对应代码 11、0、100、101，平均码长 5/3 ≈ 1.667 bit，平均信息量约 1.626 bit。平均码长与信息量不是同一个量。
H|应会完成
P|进制互换；判断表示范围与溢出；补码加减、符号扩展；区分纯二进制、BCD 和格雷码；按照代码树解码。

@c2|第2章 逻辑代数：公式与描述
来源：L03 p6-10、L04 p1-9；课本 2.1-2.5，p20-36。
H|基本运算与复合运算
P|与 AB：两个条件都满足；或 A+B：至少一个满足；非 A'：取反。这里的“+”表示逻辑或，不能按算术加法理解。异或 A⊕B 表示不同为 1，同或表示相同为 1。
F|A⊕B = A'B + AB'；(A⊕B)' = AB + A'B'。
H|高频公式
T|类别|公式
R|恒等、互补|A+0=A；A·1=A；A+A'=1；AA'=0
R|幂等、吸收|A+A=A；AA=A；A+AB=A；A(A+B)=A
R|展开与合并|A(B+C)=AB+AC；A+BC=(A+B)(A+C)
R|常用化简|A+A'B=A+B；AB+AB'=A
R|德摩根|（AB）'=A'+B'；（A+B）'=A'B'
R|共识项|AB+A'C+BC=AB+A'C
H|三个基本定理
B|代入定理：某个变量可用同一逻辑表达式替代，等式仍成立。
B|反演定理：交换与、或，交换 0、1，对变量取反，可求出原函数的反函数；保留正确的括号层次。
B|对偶定理：交换与、或以及 0、1，原变量和反变量保持原样，得到对偶式。对偶式不等于反函数。
H|逻辑函数的表示与互换
B|真值表枚举所有输入组合；逻辑式表达变量关系；逻辑图表示门电路连接；波形图按时间描述输入输出；卡诺图支持直观化简；HDL 可交给工具仿真、综合。
B|真值表转与或式：每行输出为 1 对应一个最小项，取值 1 写原变量，取值 0 写反变量，最后逻辑相加。
B|N 变量共有 2ᴺ 个最小项和最大项。最小项 mᵢ 在第 i 个输入组合为 1；最大项 Mᵢ 在第 i 个输入组合为 0。
F|Y = Σm(输出为 1 的编号) = ΠM(输出为 0 的编号)。
P|例如按 ABC 的位序，m₅=AB'C，M₅=A'+B+C'。编号前必须固定变量位序。

@c2|第2章 逻辑代数：化简与无关项
来源：L05 p1-6；课本 2.6-2.7，p37-49；Q-M 法见 2.6.3。
H|卡诺图的本质
P|将最小项按格雷码顺序排列，使几何相邻对应逻辑相邻。常见行列顺序是 00、01、11、10；左右边界、上下边界相邻，四角也能组成一组。
H|与或式化简步骤
B|① 固定位序，依据真值表或最小项编号填 1、0、X。
B|② 圈出由 1 和可选 X 组成的矩形，大小必须为 1、2、4、8……格；不能把确定的 0 圈进去。
B|③ 优先选择大圈，覆盖全部确定的 1；允许重复覆盖。满足覆盖要求后，尽量减少项数和每项因子数。
B|④ 每圈只保留不变化的变量：一直为 1 写原变量，一直为 0 写反变量；变化的变量消去。
B|⑤ 将各圈乘积项相加；回代所有有效输入验证。
F|N 变量中的 2ᵏ 格圈，能够消去 k 个变量，留下 N-k 个因子。
H|无关项怎么用
B|约束项：输入条件保证不会出现的组合；任意项：输出取 0 或 1 都不影响功能的组合。两者可作为化简时的 X。
B|X 可以按需要当 0 或 1，但不要求全部覆盖。使用 X 的目的是扩大圈或减少圈数。
B|只有题目明确的约束才能使用。例如 BCD 模块若输入保证为有效 BCD，1010-1111 可作为无关项；若还要求伪码报警，就不能这样处理。
H|公式法、图解法与列表法
T|方法|适合的情况|关键检查
R|公式法|式子已有明显可合并、吸收部分|每一步都保持逻辑等价
R|卡诺图法|变量数较少、需要直观找相邻项|格雷码顺序、跨边界相邻、完整覆盖
R|Q-M 列表法|课件中的机器化简补充|按 1 的个数分组，逐轮合并，再选择覆盖
H|易错点与练习目标
P|最简表达式可能不唯一。先检查功能正确，再检查是否最简。斜对角不相邻，3 格或 6 格不能成为一圈。圈 0 求或与式时，变量极性与圈 1 求与或式不同，应按最大项规则推导。
P|应能把真值表、标准形式、卡诺图、逻辑图互相转换，并说明每个无关项的来源。

@c3|第3章 门电路：电平与器件基础
来源：L05 p6-7、L06-L08、L10 p6、L11；课本 3.1、3.2、3.3.1、3.4.1。
H|从连续电压到 0/1
P|逻辑值通过电压范围表达。输出必须给出足够明确的高、低电平，输入判定范围之间留出容差，使噪声和器件误差不至于破坏级联逻辑。
F|高电平噪声容限 NMH = VOH(min) - VIH(min)。
F|低电平噪声容限 NML = VIL(max) - VOL(max)。
P|VIH 是可接受高输入的最低电压，VIL 是可接受低输入的最高电压；VOH、VOL 是对应输出保证值。必须按保证值与最不利情况检查。
H|半导体、PN 结和二极管
B|本征半导体有电子与空穴两类载流子。N 型以电子为多数载流子，P 型以空穴为多数载流子，整体仍保持电中性。
B|PN 结由扩散与漂移达到平衡形成耗尽层；正向偏置有利于导通，反向偏置通常截止。结电容与电荷存储影响开关速度。
B|分析二极管电路时，根据条件选择理想模型、恒压降模型或更精细的模型；先假设状态，再算电压、电流，最后验证假设。
B|二极管与门、或门能实现逻辑，但存在电平偏移、带负载能力差的问题，不能忽略级联后的电平退化。
H|MOS 管与 BJT 的开关判断
T|器件|开关分析重点|常见误区
R|增强型 NMOS|VGS 与阈值比较；导通后再判线性区或饱和区|MOS 饱和区不等同于 BJT 饱和导通
R|增强型 PMOS|看 VSG 与阈值绝对值；与 NMOS 互补|把 VGS 的正负方向套反
R|NPN BJT|截止、放大、饱和；核算基极驱动是否充足|饱和时不能仍令 IC=βIB
H|BJT 反相器的计算路线
P|输入低时检查可靠截止；输入高时算 IB，估计 IC(sat)=(VCC-VCE(sat))/RC，验证 βIB ≥ IC(sat)，并确认低输出电平满足后级要求。实际开关设计要留驱动余量。
P|课件还介绍了结型场效应管等器件背景；复习时将器件物理、等效模型和门电路功能联系起来。

@c3|第3章 门电路：CMOS 原理与动态特性
来源：L08 p3-5、L09-L10；课本 3.3.2-3.3.5，p73-91。
H|CMOS 反相器与互补网络
B|低输入：PMOS 上拉导通、NMOS 下拉截止，输出高；高输入：NMOS 下拉导通、PMOS 上拉截止，输出低。
B|有效稳态下，一条通路导通、另一条截止，输出被明确驱动。两路同时导通会产生贯通电流；两路同时截止则输出悬空。
B|设计静态互补 CMOS 门时，先用 NMOS 网络实现“输出应为 0”的条件，再建立 PMOS 对偶网络：串联与并联互换。
P|例如 Y=(AB)'：下拉 NMOS 串联，上拉 PMOS 并联。Y=(A+B)'：下拉并联，上拉串联。下拉导通条件对应 Y'，不能直接当成 Y。
H|静态特性
B|电压传输特性给出输入与输出关系；需识别高输出、低输出、过渡区以及 VIL、VIH 的边界。
B|带负载后输出电压会变化，因此电平匹配与电流能力需同时检查。CMOS 输入静态电流小，但输入电容仍会形成动态负载。
H|动态特性：最长与最短延迟
T|参数|含义|使用位置
R|tpd|输入有效变化到输出保证稳定的最大延迟|建立时间、最长路径、吞吐率
R|tcd|输入变化到输出可能开始变化的最小延迟|保持时间、最短路径
R|tPLH、tPHL|输出低到高、高到低的传播延迟|按输出变化方向选用
P|路径上的门延迟逐级相加；系统最大延迟取最长路径，最小延迟取最短路径。电容越大、驱动越弱，输出充放电越慢。
H|功耗与速度
F|电容充放电功耗约为 P = α C VDD² f。
P|这里 α 表示每个时钟周期内平均发生的 0→1 充电次数；连续方波每周期充电一次时 α=1。总功耗还包括短路电流与静态泄漏等。提高电源电压可能改善驱动与容限，也会增加动态功耗。
H|应会完成
P|读传输曲线；算噪声容限；判断互补网络功能；画 NAND/NOR 的晶体管连接；求级联延迟并说明负载电容的影响。

@c3|第3章 门电路：TTL、输出结构与接口
来源：L10 p3-5、L12-L13 p1-4；课本 3.3.5-3.3.7、3.4、3.7。
H|TTL 门电路
P|TTL 反相器由输入级、倒相级、推拉输出级组成。按输入高低分别判断各管状态，再得到输出电平。推拉结构改善驱动，但不能直接把多个推拉输出并在一起。
H|输出结构比较
T|结构|外部连接与作用|关键限制
R|推拉输出|主动提供高、低电平|多个输出直接并联会形成争用
R|OC / OD|集电极 / 漏极开路，外接上拉电阻|可实现线与；电流、上拉电压有上限
R|三态输出|使能时驱动，关闭时输出 Z|Z 是高阻，不是逻辑 0；总线上需控制使能
R|CMOS 传输门|NMOS 与 PMOS 配合构成双向开关|控制互补，信号范围受电源条件限制
H|扇出与接口
F|静态扇出 ≤ floor[min(IOH能力 / IIH负载，IOL能力 / |IIL负载|)]。
B|电平匹配：前级 VOH(min) ≥ 后级 VIH(min)，前级 VOL(max) ≤ 后级 VIL(max)。
B|电流匹配：分别核算高电平拉电流和低电平灌电流。并联输入的电流应求和，不能只数芯片个数。
B|动态匹配：输入电容和连线电容会增加延迟；静态扇出足够不代表高速时仍能可靠工作。
H|OC/OD 上拉电阻的上下限
F|Rmax = (VPU - VOH要求) / (n·IOH漏电 + m·IIH)。
F|Rmin = (VPU - VOL允许) / (IOL能力 - m·|IIL|)。
P|按“全部输出管截止”的最坏情况求 Rmax；按“仅一个输出管导通”的最坏情况求 Rmin。要求分母为正，并且 Rmin ≤ R ≤ Rmax；若不存在可行区间，需改变驱动、负载或器件。
H|复习检查
P|分清 VIL/VIH 与 VOL/VOH；注意手册电流正负号，能力比较通常取幅值；辨认低有效使能。CMOS 输入应接到确定电平，使用时按器件要求考虑静电、过流与锁定问题。

@c4|第4章 组合逻辑：分析与设计
来源：L13 p4-5、L14、L15 p1-7；课本 4.1-4.5，p146-183。
H|本章主线
P|组合电路的稳态输出只由当前输入决定，不依赖历史状态。设计时把“实际问题”变成明确的输入、输出、编码和真值表，再选择门电路或常用模块实现。
H|分析与设计的步骤
B|分析：从逻辑图逐级写表达式 → 化简 → 列真值表或功能表 → 解释实际功能。内部节点应命名，避免直接跳到结论。
B|设计：定义输入输出及有效电平 → 建立真值表 → 确定约束和无关项 → 选择器件 → 化简与连线 → 验证所有有效输入。
B|层次化与模块化：把复杂系统分成接口清楚的子模块，再复用译码器、选择器、加法器等模块。
H|常见模块
T|模块|核心功能|需要检查
R|编码器|多条输入转换成较少位代码|普通编码器通常只允许一个有效输入
R|优先编码器|多个有效输入时取最高优先级|有效极性、优先顺序、扩展输出
R|译码器|n 位输入对应最多 2ⁿ 条输出|选通条件与输出是否低有效
R|数据选择器 MUX|按照地址选一路输入送输出|地址位序、使能、数据输入极性
R|数值比较器|输出 A>B、A=B、A<B|先比较高位，高位相等才看低位
H|用模块实现逻辑函数
B|译码器：n 变量函数可分解成最小项之和。74HC138 的有效输出是最小项的反相，组合时要结合德摩根变换。
B|MUX：选择若干变量作地址，把剩余变量对应的函数接到数据输入，可用 0、1、变量或变量反相实现。
F|2 选 1：Y = A'D0 + AD1。
P|例如 Y=A⊕B，取 A 为地址，D0=B，D1=B'。先写 A=0、A=1 时的函数，再接线，比直接背接法可靠。

@c4|第4章 组合逻辑：加法与竞争-冒险
来源：L14 p3-5、L15 p7-12；课本 4.4.4、4.6-4.9；PLD 结构另见补充页。
H|加法器与算术模块
F|半加器：S=A⊕B；C=AB。
F|全加器：S=A⊕B⊕Cin；Cout=AB+(A⊕B)Cin。
P|全加器考虑低位进位；半加器不考虑。串行进位的多位加法器结构简单，但进位逐级传播，位数越多关键路径越长。
F|进位产生 Gᵢ=AᵢBᵢ；进位传播 Pᵢ=Aᵢ⊕Bᵢ；Cᵢ₊₁=Gᵢ+PᵢCᵢ。
B|先行进位把递推式展开，以更多组合逻辑换取更短延迟。算最长路径时要按实际结构，不能把“位数”直接当成门数。
B|补码加减器可以用控制 F 对 B 逐位异或，并令初始进位为 F：F=0 做 A+B，F=1 做 A+B'+1，即 A-B。
H|为什么会有冒险
P|同一输入经不同路径到达输出的时间不同，可能在切换过程中产生短暂毛刺。逻辑表达式等价，只保证稳定时功能相同，不能保证过渡波形相同。
B|静态 1 冒险：理应保持 1，却短暂变成 0。静态 0 冒险：理应保持 0，却短暂变成 1。
B|卡诺图检查与或电路：单一输入变化时，相邻两个 1 若没有被同一乘积项覆盖，可能有静态 1 冒险。
F|Y=AB+A'C：B=C=1 时，A 改变可能产生冒险；加入 BC 得 Y=AB+A'C+BC。
H|消除方法与条件
B|增加共识项：在逻辑功能不变的前提下覆盖切换过程；上述卡诺图检查适用于相应两级与或实现和单变量变化。
B|引入选通：在电路稳定后才取输出。滤波电容能削弱窄毛刺，但同时影响电路速度，应按题目条件分析。
B|多输入同时改变可能产生更复杂的瞬态；不能把单变量冒险判据当成所有情况的保证。
H|显示、HDL 与 EDA
P|七段译码器需要核对共阴/共阳与输出极性；7448 的试灯、灭灯、灭零输入及灭零输出用于多位显示控制。HDL、仿真、综合和硬件下载是不同环节，功能验证与时序验证都要进行。

@c5|第5章 存储电路：锁存器与触发器

H|存储的本质与动作方式
P|正反馈可形成两个可保持的稳定状态，用来存储 1 bit。锁存器在使能电平期间响应输入；边沿触发器在指定时钟边沿采样。逻辑功能分类与触发方式分类是两个维度。

T|类型|次态方程|功能与约束

T|Q→Q*|D|T|J、K

R|0→1|1|1|J=1，K=X
R|1→0|0|1|J=X，K=1

H|画波形的顺序

P|禁止输入组合、异步控制释放、未满足时序条件时，不应强行给出唯一的确定输出。

@c5|第5章 存储电路：寄存器与存储器
来源：L17 p7-8、L18 p1-7；课本 5.4-5.5，p229-249。
H|寄存器、容量和地址
B|N 位寄存器由 N 个存储位组成，用来保存一组代码。课件器件例包括 74HC175，需识别并行输入、时钟及异步复位。
B|存储器容量写成“字数 × 每字位数”。A 根地址线最多选择 2ᴬ 个地址；W 位数据宽度时总容量是 2ᴬ×W bit。
P|例如 1024×8 bit = 8192 bit = 1024 Byte，需要 10 根地址线、8 根数据线。字长是器件或系统规定的宽度，并非固定等于一个字节。
H|类型比较
T|类型|存储方式与特点|掉电 / 改写
R|SRAM|双稳态存储单元，保持期间无需刷新|易失；可读写
R|DRAM|电容存电荷，需要刷新|易失；可读写
R|掩模 ROM|制造时固定数据|非易失；用户不能改写
R|PROM|一次性编程|非易失；编程后不能重写
R|EPROM|浮栅存储，课件介绍紫外线擦除|非易失；擦除后可重写
R|EEPROM / Flash|电擦除存储|非易失；擦写单位和机制需区分
H|容量扩展
B|位扩展：字数够、位宽不够。地址、片选、读写控制并联，各芯片数据端分别接不同位。八片 1024×1 → 1024×8。
B|字扩展：位宽够、字数不够。低位地址并联，高位地址译码产生片选，同一时刻仅选一片，共用数据总线。四片 256×8 → 1024×8。
B|字、位都不够时组合扩展。先分配高位片选地址与低位片内地址，再分配每组数据位，核查地址区间是否连续、是否重叠。
H|存储器实现逻辑函数
P|把输入变量接地址线，把所需输出值逐地址写入数据表，数据线就是输出函数。n 输入、m 输出的完整真值表需 2ⁿ×m bit。ROM 由此可作为组合函数查表单元。
H|应会完成
P|算位宽、容量、地址线数和芯片数；画字扩展/位扩展连接；写片选表达式和地址范围；从 ROM 数据表读出函数。检查读写极性与高阻输出，避免未选芯片驱动共享总线。

F|次态 Q*=G(X,Q)；Mealy 输出 Y=F(X,Q)；Moore 输出 Y=F(Q)。
P|状态记录历史信息，使电路能处理序列和控制流程。同步系统使用共同的时钟事件更新状态；异步电路需考虑各级变化的先后与延迟。
H|分析已有电路

B|⑤ 画电路，检查全部输入分支及未用状态，验证自启动与时序。

R|输出依赖|现态|现态与当前输入
R|状态图标注|输出写在状态内|输入/输出写在转移边上
R|时序特点|通常随状态更新而改变|可能在一个周期内随输入变化

@c6|第6章 时序逻辑：移位与计数
来源：L19 p3-5、L20 p1-6；课本 6.3，p271-309。
H|移位寄存器
P|在时钟作用下，各级接收相邻一级原来的值，形成左移或右移。74LS194A 等通用移位寄存器还具有保持、并行装入、异步清零等方式；根据功能表检查模式控制与串行输入。
H|计数器类型与规律
B|同步计数器：所有触发器共用时钟，组合逻辑决定各位翻转条件。二进制加法中，第 i 位在所有较低位为 1 时翻转；减法中在较低位全为 0 时翻转。
B|异步计数器：低位的输出变化触发更高位，翻转逐级传播；读瞬态状态时必须考虑传播延迟。
B|按编码区分二进制、十进制等；按方向区分加、减、可逆。计数模数等于循环中的不同稳定状态数。
H|常见器件控制
T|器件|课件中的功能|关键区分
R|74161|同步二进制计数器|异步清零、同步预置、计数使能
R|74160|同步十进制计数器|正常循环 0-9，控制端功能同样要检查
R|74LS193|二进制可逆计数器|双时钟上/下计数，另一计数输入需置于规定电平
H|任意 M 进制：避免差一个状态
B|已有 N 进制且 M<N：利用反馈清零或预置跳过 N-M 个状态。
B|异步清零形成从 0 开始的 M 模计数：检测进入 M 的状态后立即清零；稳定循环为 0 至 M-1，但译码 M 会短暂出现。
B|同步清零或同步装入：在 M-1 状态产生控制，下一时钟沿回到起点；若检测 M 再等一拍就多计了一个状态。
B|若从 P 计到 N-1，再同步装入 P，循环长度为 N-P。应以状态序列验证预置数和触发时刻。
H|扩展与应用
P|M>N 时可级联：并行进位共用时钟，以低位进位控制高位使能；串行进位用低位信号作为高位时钟。两者的时序不同。不可分解的模数可先扩展成更大计数范围，再整体清零或预置。
P|计数器+译码器产生顺序节拍；计数器+MUX 按地址选择数据，产生指定序列。解题时列出一个完整循环，确认周期、输出极性与复位起点。

@c6|第6章 时序逻辑：时序约束与流水线
来源：L17 p4-6、L21 p7-9、L22 p2-7、L23 p1-2；课本 5.3.5、6.6；流水线为课件补充。
H|建立时间与保持时间（同一时钟、忽略时钟偏斜）
F|建立约束：Tclk ≥ tpcq + tpd(最长组合路径) + tsetup。
F|保持约束：tccq + tcd(最短组合路径) ≥ thold。
B|tpcq 是时钟到 Q 的最大延迟，tccq 是最小延迟。建立看最长路径，保持看最短路径，两者都要满足。
B|降低时钟频率可改善建立时间，但不能解决这里的保持时间违反；保持问题通常需在过短路径加入延迟等。
P|课件例：tpcq=50 ps，最长组合延迟 105 ps，tsetup=60 ps，则周期至少 215 ps，频率上限约 4.65 GHz。tccq=30 ps、最短组合延迟 25 ps、thold=70 ps 时，保持失败；将最短路径延迟增至 50 ps 后，30+50≥70，才能通过。
H|延迟与吞吐率不是同一指标
T|形式|单个任务延迟|稳态吞吐率
R|组合电路|总组合传播延迟|按一次输入稳定到输出完成的周期计算
R|K 级流水线|约 K 个时钟周期|填满后，理想情况下每周期一个结果
R|复制慢模块并交织|单个模块的执行延迟仍存在|不同模块错峰接收任务，提高接收速率
H|流水线设计规则
B|每条输入到输出路径跨越相同的流水级数；汇合处来自同一个任务的数据必须对齐。短路径也可能需要补寄存器。
B|最慢一级决定时钟周期，还要计入寄存器开销及建立时间。各级延迟尽量均衡。
B|更多级数可能提高吞吐率，但会增加寄存器、延迟周期和控制成本，不能直接认为单个任务一定更快。
F|理想 K 级、周期 T 的流水线：完成 N 个任务约需 (K+N-1)T。
P|该式假设每周期可输入一个任务、没有停顿，且第一个结果在 K 个周期后得到。交织与流水线结合时，仍需跟踪每个样本通过各模块、寄存器的时刻。

@c7|第7章 脉冲电路：施密特与 RC 分析
来源：L23 p7-10、L24 p1-6、L25 p1；课本 7.1-7.4，p349-374。
H|三种电路的作用
T|类型|状态与触发|典型用途
R|施密特电路|上、下翻转阈值不同，有回差|波形整形、鉴幅、提高抗扰能力
R|单稳态电路|一个稳态、一个暂稳态；触发后自动返回|定宽脉冲、延时、定时
R|多谐振荡器|无稳定状态，交替经历暂稳态|自激矩形波、时钟、脉冲发生
H|施密特：先判断输入变化方向
F|回差电压 ΔVT = VT+ - VT-。
P|输入上升达到 VT+ 才按相应方向翻转，下降达到 VT- 才反向翻转；两阈值之间输出取决于先前状态。输出是反相还是同相，要看实际电路，不可只根据“施密特”名称判断。
H|RC 三要素法
F|v(t) = v∞ + (v0 - v∞) exp(-t/τ)；τ = Req C。
F|从 v0 到阈值 vT 的时间：t = Req C · ln[(v0-v∞)/(vT-v∞)]。
P|对数比值应为正，计算结果应为正时间。v0 是该阶段开始瞬间的值，v∞ 是在当前开关状态一直保持时的终值，Req 是电容看到的等效电阻。
H|分析脉冲电路的固定步骤
B|① 找稳态或暂稳态，判断门输出和开关状态，画关键节点波形。
B|② 找决定跳变的电容电压或门输入电压，为每个充放电阶段画等效电路。
B|③ 求 v0、v∞、Req 与门阈值，再求该阶段时间。
B|④ 电容两端电压不能突变，但电容某一端随门输出跃变时，另一端可同时跃变；重新确定下一阶段初值。
B|⑤ 累加各阶段时间求周期，或用指定阶段时间求脉宽；检查恢复时间及触发条件。
H|多谐与单稳态的检查
P|环形振荡器靠反相和延迟振荡；RC 振荡器的周期由充放电与阈值决定。单稳态还需区分可重复触发与不可重复触发，不能把所有电路的脉宽都套成同一 RC 系数。

@c7|第7章 脉冲电路：555 定时器
来源：L25 p1-4；课本 7.5，p375-381；常用接法公式根据课件电路整理。
H|核心功能
P|标准 555 由分压网络、两个比较器、锁存器、放电管和输出级组成。常用阈值为 VCC/3 与 2VCC/3；控制电压端改变比较基准时，不能继续套用默认阈值。
B|低有效复位为 0：输出低，放电管导通，优先于常规触发。
B|触发端低于 VCC/3：在其他条件允许时置位，输出高，放电管截止。

H|三种典型接法
T|接法|连接与工作过程|主要结果
R|施密特|触发端与阈值端接同一输入|默认上阈值 2VCC/3，下阈值 VCC/3

H|标准双电阻多谐接法
F|tH = (RA+RB)C ln2；tL = RB C ln2。
F|T = (RA+2RB)C ln2；f = 1/T；高电平占空比 q=(RA+RB)/(RA+2RB)。
P|这些公式对应电容通过 RA+RB 充电、通过 RB 放电的标准接法。若加入二极管或改变放电路径，需重新求等效电阻。此处占空比定义为高电平时间占周期的比例。
H|解题模板
B|画充、放电电流路径，检查放电管与输出的对应关系。
B|把电容初值、终值与阈值代入三要素法，推导时间，而非先找公式硬套。
B|单稳态检查触发脉冲是否过宽、能否在暂稳态期间重复触发；检查下一次触发前电容是否恢复。
H|理解例题
P|单稳态取 R=100 kΩ、C=0.1 μF，RC=10 ms，脉宽约 10.99 ms。单位换算后再相乘。该结果采用标准阈值和电容初值为零的近似。

R|倒 T 形电阻网络|由 R、2R 网络形成二进制权重|电阻种类少，利于集成与匹配
R|权电流型|开关控制加权电流求和|重点看电流权重与输出转换
R|双极性输出|对代码或输出做偏移、极性处理|需保证符号与零点对应正确
H|课件常见的归一化理想公式
F|D = Σ bᵢ2ⁱ；反相单极性 DAC：VO = -VREF·D/2ⁿ。
F|1 LSB 的电压幅值 Δ = |VREF|/2ⁿ；最大代码 Dmax=2ⁿ-1。
P|该公式假设课件相应电路的反馈电阻与网络比例。若 Rf 或参考端定义改变，应从求和电流重新推导比例与符号。最大代码输出距离参考端幅值仍差一个 LSB。
H|分辨率、精度与速度
B|分辨率是最小代码步进对应的模拟变化，位数增加使理想步长减小；精度反映实际输出与理想关系的偏差。
B|误差可来自增益、零点漂移、非线性、电阻与开关偏差、参考源不稳定等。分辨率高不保证实际误差小。
B|转换速度要关注建立到指定误差带所需的时间，不能只看输出开始改变的时刻。
H|理解例题
P|8 位、VREF=5 V 的上述 DAC：1 LSB=5/256≈19.53 mV。D=128 时 VO=-2.5 V；D=255 时 VO≈-4.9805 V。满量程代码不是 -5 V。
H|双极性输出与误差估算
P|课件通过翻转补码符号位、配合模拟零点偏移，使负端、零点、正端与代码一致。先检查三个关键代码，再写传输关系。参考电压误差引起的输出误差近似按代码比例放大，应使用最不利代码检查允许误差。

@c8|第8章 转换电路：ADC 类型与比较
来源：L25 p9-13；课本 8.4、8.6-8.7，p404-427；课件另介绍计数型。
H|ADC 的三个基本环节
P|采样把连续时间信号变成离散时间样本；量化把幅值映射到有限等级；编码给每个等级赋数字代码。取样-保持属于课本 8.5；课件章末将该节列入“不要求”范围，不能据此推断当前学期要求。
H|主要类型
T|类型|原理|速度与代价
R|并联比较型|多个阈值同时比较，再编码|快；n 位典型需要 2ⁿ-1 个比较器
R|计数型（补充）|计数器驱动 DAC，逐级与输入比较|简单；最坏接近 2ⁿ-1 次计数
R|逐次逼近型 SAR|从最高位开始试探，保留或清除每一位|约 n 次比较；总时钟数取决于控制结构
R|双积分型|固定时间积分输入，再用反向参考积分回零|较慢；适合稳定测量，具有积分平均效果
R|V-F 型|把输入电压转换成频率再计数|输出计数反映测量窗口内的频率
H|逐次逼近的思路
P|先试最高位 1，经 DAC 生成比较电压；若超过输入，则清该位，否则保留。逐位试到最低位。课件给出的某实现用 n+2 个时钟，不应把“n 次比较”与“总转换时钟数”混为一谈。
H|双积分的关系
F|理想条件下：T2 = (VI / |VREF|)T1；D = fclk·T2。
P|固定 T1 对输入积分，再用相反极性的参考回零。两阶段使用相同 R、C 时，理想推导中 R、C 抵消；实际仍需考虑比较器、参考源和时钟等误差。
H|量化误差与指标
F|均匀量化常用步长 Δ=输入量程跨度/2ⁿ；理想四舍五入量化误差不超过 Δ/2。
P|该误差界对应四舍五入、未超量程等条件；截断方式、端点定义或课件特定阈值安排可能不同。位数是分辨率指标，转换误差是精度指标，转换时间/采样率是速度指标。
H|复习范围的来源
P|L25 p13 有本章回顾，强调 DAC 计算、双极性输出、ADC 原理及速度精度比较；其“不要求内容”和 p14 考试通知属于 2025 年课件记录。教学安排.pdf 标注 2026 春，讲次也不同，本总结按实际 PDF 内容对应课本。

@extra|课件补充：PLD、FPGA 与 EDA
来源：L04 p4-5、L15 p9-12、L22 p1、L23 p2-7；课本 4.6-4.8、6.5、附录一 p435 起。
H|如何与课本对应
P|PLD 不是单独的“第7章”。课件在组合逻辑介绍后先讲 EDA 与 PLD 概念，时序电路之后再展开器件结构。合订本在第4章、第6章与补充书签中都提供入口，原页面只保留一份。
H|结构比较（按课件介绍的器件类别）
T|类别|结构或实现方式|关键特点
R|PROM|地址译码与存储表|可将真值表作为逻辑功能
R|FPLA|与阵列和或阵列均可编程|较灵活地实现与或结构
R|PAL|可编程与阵列、固定或阵列|结构受固定或阵列约束
R|GAL|与或阵列加可编程输出宏单元|可改写，输出结构更灵活
R|EPLD / CPLD|更复杂的逻辑块与连接资源|理解宏单元、逻辑块、互连与输出控制
R|SRAM 型 FPGA|CLB、IOB、互连、配置 SRAM|上电需装载配置，掉电配置丢失
H|FPGA 中的逻辑实现
B|LUT 是查找表：把输入视为地址，表项对应函数输出，可实现一定输入数以内的组合函数。
B|D 触发器存储状态，MUX 选择数据，互连资源连接各块，I/O 块连接外部信号。
B|课件讲的是 SRAM 型配置 FPGA；不能把其掉电特征推广到所有可编程器件。
H|EDA 的工作流程
P|需求与接口定义 → HDL 或原理图描述 → 功能仿真 → 综合到逻辑资源 → 实现并检查时序 → 配置/下载 → 硬件验证。课件的软件与器件举例保留为学习背景，不作为当前产品推荐。
H|HDL 的基本认识
P|组合逻辑可用连续赋值描述，例如 assign y = (~a & b) | (a & ~b)。时序逻辑要明确时钟、复位与状态寄存器。程序文本描述的是硬件结构和行为，需要考虑多个模块的并行工作。
H|应会完成
P|区分仿真与综合；说明 LUT、触发器、互连的作用；把真值表映射为 ROM/LUT；区分组合描述与状态更新；理解时序检查为何不能由功能正确替代。

H|第一轮：建立概念和定位能力
B|第1章：同一代码如何解释？先定编码、位宽、小数点，再算数值。

B|第4章：如何实现无记忆的功能？选择模块，核对极性和使能，最后检查冒险。
B|第5章：状态如何保存？区分动作方式、逻辑功能、控制优先级和存储器组织。
B|第6章：状态如何更新？分析/设计 FSM，验证计数循环、未用状态和动态时序。

B|第8章：代码与模拟量如何对应？检查范围、步长、误差与转换时间。
H|第二轮：用固定流程做题
T|题型|先确定|最后验证
R|化简与组合设计|输入约束、有效极性、变量位序|全部有效输入；必要时检查过渡冒险
R|门电路与接口|保证电平、电流方向、负载|高低两种状态及最坏情况
R|触发器与时序波形|复位优先级、有效沿、动作方式|次态、传播延迟、建立保持

H|第三轮：重点辨析
P|进位 ≠ 有符号溢出；BCD ≠ 纯二进制；对偶 ≠ 反函数；MOS 饱和 ≠ BJT 饱和；高阻 ≠ 逻辑 0；锁存器 ≠ 边沿触发器；建立 ≠ 保持；吞吐率 ≠ 单任务延迟；分辨率 ≠ 精度。
