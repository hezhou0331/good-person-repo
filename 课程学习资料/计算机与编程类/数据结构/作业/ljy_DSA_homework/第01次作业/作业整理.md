## 必会知识点

- **逻辑结构**讲元素间的关系：线性结构、非线性结构（树、图等）。
- **存储结构**讲如何存：顺序存储用连续空间；链式存储用指针表示连接。链式存储也能实现树和图。
- 顺序表按下标访问为 O(1)，中间插删通常要移动元素；链表按位置查找通常为 O(n)，已知所需节点后可通过修改指针插删。
- **ADT=(D,R,P)**：数据对象、数据关系、基本操作。规定操作含义和效果，不限定实现算法。
- **数据元素与数据项**：一条学生记录是元素，学号、姓名等是数据项。

## 复杂度解题方法

1. **表达式**：化简 → 比增长速度 → 去掉常数和低阶项。本次涉及 n < n log n < n^(3/2)。
2. **倍增循环**：列出 1、3、9……，用 3^k 与终止上限比较，得到对数级次数。
3. **嵌套循环**：内层上限依赖外层变量时，从内到外求和，不能只数循环层数。
4. **递归**：先数本层工作量、实际递归次数、子问题规模，再写递推式。

## 重点：第 12 题（明确表示不太会）

```c
int recur(int n){
    if(n==1){
        return 1;
    }
    int k=0;
    while(k<n) k++;
    if(n%2==0)
        k = k*recur(n-1);
    else
        k = k+recur(n-1);
    return n+k*k;
}
```

选项：A. O(n)；B. O(n²)；C. O(n!)；D. O(2ⁿ)。

**答案 B**：每层循环 n 次；if/else 只走一个分支，因此只递归一次。

T(n)=T(n−1)+Θ(n)，总工作量 n+(n−1)+…+2+Θ(1)=Θ(n²)。

易错点：`k*recur(n-1)` 是一次递归加一次乘法，不是递归 k 次；返回值大小不等于操作次数。按题意采用基本运算常数耗时模型，n 为正整数。

## 第 13 题：三层循环

```c
int x = 0;
for (int i = 1; i <= n; i++){
    for (int j = 1; j <= i * i; j++) {
        for (int k = 1; k <= j; k++){
            x++;
        }
    }
}
```

选项：A. O(n³)；B. O(n⁴)；C. O(n⁵)；D. O(n⁶)。

**答案 C**：固定 i 时，执行次数为 Σ(j=1 到 i²)j=(i⁴+i²)/2；再对 i=1 到 n 求和，得到 Θ(n⁵)。

## 补充知识点：四种排序（2026-10-09）

用户明确表示：容易记不住算法含义和复杂度。本节为补充知识点，不对应新增作业题，也不标为截图错题。

| 算法 | 核心动作 | 最好时间 | 平均时间 | 最坏时间 | 辅助空间 | 稳定性 |
|---|---|---|---|---|---|---|
| 直接插入 | 把下一个数插入前面已排好的部分 | O(n) | O(n²) | O(n²) | O(1) | 稳定 |
| 冒泡 | 相邻逆序就交换，每趟把最大值送到末尾 | O(n)，需无交换则提前结束 | O(n²) | O(n²) | O(1) | 稳定 |
| 简单选择 | 在未排序部分选最小值，与其首位交换 | O(n²) | O(n²) | O(n²) | O(1) | 不稳定 |
| 常规数组归并 | 分成两半分别排序，再合并两个有序段 | O(n log n) | O(n log n) | O(n log n) | O(n) | 稳定 |

- **插入像整理手牌**：已有序时每个新数比较一下即可；逆序时移动次数为 1+2+…+(n−1)，所以 O(n²)。二分查找只减少比较，数组移动仍使平均/最坏时间为 O(n²)。
- **冒泡像相邻接力**：每趟 O(n)，最多 O(n) 趟，合计 O(n²)。已有序时，一趟无交换就结束；无提前结束的普通实现最好也为 O(n²)。
- **选择像选最小上台**：即使已有序，每趟仍扫描剩余元素，比较总数固定为 n(n−1)/2。
- **归并像分组后排队合流**：共约 log₂n 层，每层合并总工作量 O(n)，故 O(n log n)。合并需 O(n) 临时数组；递归栈 O(log n)，总辅助空间仍为 O(n)。
- **稳定**：相同排序键的记录，排序前后的相对顺序不变。插入不越过相等元素、冒泡只交换严格逆序、归并相等时先取左边，才能保持稳定。选择例子：[2甲, 2乙, 1] → [1, 2乙, 2甲]，相同键次序改变。
- 记忆：**插入找位置，冒泡换邻居，选择找最小，归并分再合。前三个平均平方，归并 n log n；插冒有序可线性，选择始终平方；前三个常数空间，归并线性空间；简单选择不稳定。**
