## 第1题：何时采用链表表示线性表

题目：对线性表，在下列哪种情况下应当采用链表表示？

- A：经常需要随机地存取元素。
- B：经常需要进行插入和删除操作。
- C：表中元素需要占据一片连续的存储空间。
- D：表中元素的个数不变。

**答案：B。**链表插入、删除主要修改指针，不需要搬移后续元素，适合频繁插入和删除。

核心考点：已知操作位置及所需前驱时，链表的链接修改为 O(1)；若需要先查找位置，查找通常为 O(n)。顺序表支持 O(1) 按下标随机访问，占用连续存储空间，但插入、删除通常需要移动元素。元素个数不变本身不是采用链表的理由。

记忆：**随机访问选顺序表，频繁增删选链表。**未提供用户作答，不标为错题。

术语补充：存取就是存入或读取数据。例如读取第5个元素，或修改第5个元素的值。随机存取指可以按下标直接访问任意位置，不是随机抽取元素；顺序表可直接访问第5个元素，链表通常要从头沿指针逐个找到它。

## 待巩固：列表插入排序填空（疑惑是否选 C）

题目：循环 `for (int r=0; r<n; r++)` 中，填入查找位置并插入的语句，随后执行 `p=p->succ; remove(p->pred);`。

**答案：B：`insertAfter(search(p->data, r, p), p->data);`。**用户询问是否选 C，未确认已提交选择，记录为待巩固，不标为截图错题。

核心考点：p 指向当前待排序结点，其前面恰有 r 个已排序结点。search 在这 r 个结点中返回不大于 p->data 的最右结点（无满足者返回边界前驱），因此在结果之后插入，用 insertAfter，不是 insertBefore。search 自身会在需要时多走一步到边界前驱，参数仍是实际查找范围大小 r，不能改为 r+1。

例：已排序前缀 2、5、8，当前值 7；search 返回存放 5 的结点，在 5 后插入新的 7，再让 p 指向原待排序结点的后继并删除原 7，得到 2、5、7、8。insertAfter 增加 _size，remove 减少 _size，一轮结束长度不变。实现是先创建副本，再删除原结点。

## 无序列表去重：删除前一个还是后一个重复结点

题目：`q = find(p->data, r, p); q ? remove(q) : r++;` 遇到重复时删除哪个结点？A 后一个；B 前一个。

**答案：B。**p 从左向右扫描，find 在 p 前面的 r 个数据结点中找相同值，q 指向前面的重复结点；remove(q) 删除 q，保留当前 p。三目运算等价于 `if (q != NULL) remove(q); else r++;`。

r 是当前 p 前面的已处理数据结点数。没找到重复时，下一轮前缀多一个结点，r 加一；找到重复时，删除前面的 q，再将当前 p 纳入下一轮前缀，数量一减一增，r 不变。

例：给图中原序列结点标记为 3甲、8甲、5、3乙、8乙、13甲、8丙、13乙，最终保留 5、3乙、8丙、13乙，即保留各值最后一次出现的结点。`oldSize - _size` 返回删除数；外层扫描与内层前缀查找使最坏时间 O(n²)，辅助空间 O(1)。未提供用户作答，不标为错题。

## 代码排序：删除原 P 的直接前驱

题目：L 为带头结点的单链表，P 指向非首元数据结点，排列给定代码以删除 P 的直接前驱。

**答案：cfebad。**

```c
Q = P;                                    // (c) 保存原 P
P = L;                                    // (f) 从头结点出发
while (P->next->next != Q) P = P->next;    // (e) 找待删结点的前驱
Q = P->next;                              // (b) Q 改为指向待删结点
P->next = P->next->next;                   // (a) 绕过待删结点
free(Q);                                  // (d) 释放待删结点
```

核心考点：若局部结构为 A→B→C，原 P 指向 C，待删的是 B。循环结束时 P 指向 A、Q 仍指向 C；随后 Q 改指向 B，链接改为 A→C，再释放 B。指针变量会改变指向，不要把代码后续的 P 当作原 P。定位最坏 O(n)，修改链接和释放按常规模型为 O(1)。未提供用户作答，不标为错题。

## 待巩固：有序列表查找的返回规则（A 与 C 的区别）

用户明确表示：没弄清选 A 还是 C；截图未显示已选答案，不标为截图错题。

题目：FunctionA 使用相等比较，找到返回 p，失败返回 NULL；FunctionB 从 p 向前扫描，使用 `data <= e`，补全 X、Y 并判断查找类型。

**答案：A。**FunctionB 是有序列表查找，X 为 `break`，Y 为 `return p`。

```cpp
while (0 <= n--)
    if ((p = p->pred)->data <= e) break;
return p;
```

核心考点：FunctionA 对应 find，在原 p 的 n 个前驱中找等于 e 的最右结点，未找到返回 NULL。FunctionB 对应 search，在非降序范围中找不大于 e 的最右结点；范围内无满足者时返回左边界的前驱（可能是 header），用于确定插入位置。`break` 只退出循环，随后仍执行 `return p`；`return p` 直接退出函数。

A、C 在找到满足条件的结点时效果相同；区别是循环结束后，A 返回停止位置 p，C 返回 NULL，后者不符合教材 search 的边界返回规则。`0 < n--` 至多执行 n 次循环体；`0 <= n--` 至多执行 n+1 次，多走一步到左边界前驱。哨兵的数据不应作为实际数据参与有意义的比较，实际实现可显式判断边界。

例：有序数据 2、5、8、12，查 7 返回存放 5 的结点；查 1 则返回 header，表示应插在最前面。两种查找最坏均为 O(n)。

记忆：**find 找相等，失败给空；search 找前驱，越界给位置。**

## 单链表增加头结点的目的

题目：单链表中，增加头结点的目的是为了什么？

- A：使单链表至少有一个结点。
- B：标示表结点中首结点的位置。
- C：消除表头结点特殊处理，方便运算的实现。
- D：说明单链表是线性表的链式存储实现。

**答案：C。**头结点不存放实际数据，位于首元结点之前。增加头结点后，首元结点也有前驱，插入和删除首元结点可与表中操作采用相同的链接修改规则，也方便统一处理空表。

核心考点：头指针是保存地址的指针变量；头结点是辅助结点；首元结点是第一个实际数据结点。头结点不计入数据元素个数，只有头结点的链表仍为空表。

记忆：**头结点作前驱，首元操作能统一。**

## 在单链表结点 p 之后插入结点 s

题目：在单链表指针为 p 的结点之后插入指针为 s 的结点，正确的操作是什么？

- A：`p.next=s; s.next=p.next;`
- B：`p.next=s.next; p.next=s;`
- C：`s.next=p.next; p.next=s;`
- D：`s.next=p.next; p.next=s.next;`

**答案：C。**原来为 p→q，先令 s→q，再令 p→s，得到 p→s→q。必须在覆盖 p 的后继指针前，把原后继地址存进 s 的后继指针。

```cpp
s->next = p->next;  // 新结点先连接原后继
p->next = s;        // 原结点再连接新结点
```

核心考点：题目用 `.next` 表示链接；在 C/C++ 中 p、s 为结点指针时写 `->next`。A 会使 s 指向自己，B 未正确设置 s 的后继，D 未把 s 接入主链。已知有效结点 p 和新结点 s 时，链接修改为 O(1)，尾部插入时原后继为 NULL，同样适用。

记忆：**先接后，再接前。**未提供用户作答，不标为错题。

## 第3题：两个单链表首尾相接形成循环链表

题目：ha、hb 分别为两个单链表的头指针，将 ha 的尾结点连接 hb，再将 hb 的尾结点指向 ha，返回循环链表的头指针。

**答案：B：`p->next=ha; return ha;`。**用户询问是否选 D，记录为待巩固；未确认提交，不标为截图错题。

核心代码：

```cpp
LNode *p = ha;
while (p->next != NULL) p = p->next; // 找到 ha 的尾结点
p->next = hb;                       // 接上 hb
while (p->next != NULL) p = p->next; // 找到 hb 的尾结点
p->next = ha;                       // 尾结点连回 ha，形成环
return ha;                         // 返回题目指定的头指针
```

解题方法：追踪 p 的最终位置。第二个 while 结束时，p 指向 hb 的尾结点；ha 仍指向原来的首结点。B 与 D 均正确成环，但 D 的 `return p` 返回尾结点，不符合题目要求。A、C 的 `ha=p->next` 会把此时为 NULL 的后继地址赋给 ha，不能成环。

补充：循环链表虽可从任意结点开始遍历，本题要求返回的头指针是 ha。上述操作假设两个链表非空；原题空指针分支只输出提示，没有终止执行，不能安全处理空链表。

### 第3题补充：循环链表为什么还有头指针

用户明确困惑：既然形成环，为什么还有头指针？

头指针是保存指定起点地址的指针变量，不是额外的结点。环没有天然的起点，但程序需要保存一个入口，才能访问它；本题沿用 ha 作为入口。例如 A→B→C→A，指定 ha 指向 A，则 A 是约定的起点。p 最后指向 C，也可以作为遍历入口，但题目要求返回 ha，因此选 B。`p->next=ha` 只改变尾结点的链接，不改变 ha 的指向。头指针与头结点不同，本题没有要求额外增加头结点。


## 第4题：有尾指针的单链表，哪种操作与表长有关

题目：长度 n>1 的带头结点单链表 h，尾指针 r 指向尾结点，哪种操作的复杂度与链表长度有关？

**答案：B：删除单链表的最后一个元素，时间 O(n)。**用户截图选择 B，答案正确，不标为错题。

核心考点：删除尾结点需找到其前驱，才能令前驱的 next 为 NULL，并把尾指针 r 更新为前驱。单链表只有 next，无法由 r 直接向前走，因此仍需从头遍历。

其他选项：A 删除首元结点，头结点就是其前驱，O(1)；C 在首元结点前插入，即在头结点后插入，O(1)；D 在尾结点后插入，可通过 r 直接连接新结点并更新 r，O(1)。

记忆：**尾指针方便尾插；单链表尾删仍要找前驱。**

## 待巩固：无头单链表实现集合差 A−B（截图未显示题号）

题目：A、B 为无头单链表，删除 A 中也出现在 B 中的元素，填写5处代码。用户请求讲解，未提供作答。

按空格顺序：

```c
(lnode *)malloc(sizeof(lnode))
p->next != NULL
p->next = q->next
p = p->next
B = B->next
```

核心方法：先给 A 临时增加头结点，使删除首元结点也能通过前驱 p 统一处理。外层逐个取 B 的元素；内层让 p 从临时头结点开始，检查 p->next 的数据。相等时 q 保存待删结点，令 p->next=q->next 绕过它，再 free(q)；删除后 p 不移动，继续检查新的后继。不相等时 p 才向后移动。每轮内层结束后 B 向后移动。

## 递归逆序打印单链表（截图未显示题号）

题目：补全 `void ReversePrint(ListNode* head)`，递归实现单链表逆序打印。

答案（假设 head 指向首元结点，数据字段为 data）：

```cpp
void ReversePrint(ListNode* head) {
    if (head == NULL) return;
    ReversePrint(head->next);
    std::cout << head->data << " ";
}
```

核心考点：先递归访问后继，返回时打印当前结点。对 1→2→3→NULL，递归到 NULL 停止，再依次打印3、2、1。打印语句若放在递归调用之前，会变成正序打印。只改变打印顺序，不修改链表链接。

边界：空链表直接返回。题图没有给出 ListNode 定义，字段名须与实际定义一致（若为 val，则改为 head->val）；使用 cout 需包含 iostream。若链表带不存数据的头结点，初次调用传入头结点的 next。时间 O(n)，递归栈空间 O(n)。未提供用户作答，不标为错题。
