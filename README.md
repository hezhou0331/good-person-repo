# 好人资料库

因为找我聊转系和学习资料的同学挺多，就搭了这个「好人资料库」。这里收集转系相关文件和 Q&A，也分享自己学习过程中整理的课程资料、学习网站和 AI 使用攻略，方便大家找东西。

建议大家当好人，多约饭，列计划并执行。有什么问题可以来问我，也欢迎在 [Issues](https://github.com/hezhou0331/thu-transfer-guide/issues) 留言。

使用时可以先看目标院系的接收计划，再对照培养方案了解课程安排与可能需要补修的内容。这些是历史资料，申请当年的条件、名额和时间安排请以当年学校及院系通知为准。

原文件的名称与内容均保留。2025年接收计划附件的文件头为旧式 Excel 格式，但扩展名是 `.xlsx`；如果打开时提示格式不一致，可以用 Excel/WPS 尝试打开，或将下载副本的扩展名改为 `.xls`。

欢迎通过 PR 补充转系经历、准备过程、公开文件和更新后的资料。分享经历时请注明申请年份、原院系及目标院系，方便大家判断适用范围。

## 一起补充

仓库公开，欢迎 Fork 后提交 PR，也欢迎通过 Issues 提问、纠错或提供新的资料入口。

- 新增资料时注明来源、年份和适用院系；个人经验保留作者署名。
- 提交前隐去学号、私人联系方式及其他不宜公开的个人信息，不上传个人申请表或同学名单。
- 原文件和外部资源的作者、来源及权利归属保留；请分享允许公开传播的资料。
